# Журнал изменений

**Languages:** [English](CHANGELOG.md) · **Русский** · [简体中文](CHANGELOG.zh.md)

Все значимые изменения в поддержке редакторов для Ktav (VS Code
расширение, IntelliJ плагин, LSP-сервер, общая TextMate-грамматика)
документируются здесь. Формат:
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); версии
следуют [Semantic Versioning](https://semver.org/) с pre-1.0
конвенцией: MINOR-бамп считается ломающим.

Один тег (`v0.X.Y`) выпускает все четыре подпроекта одновременно.
Изменения по подпроектам сгруппированы под заголовком версии.

Этот changelog трекает **релизы поддержки редакторов / IDE**, а не
изменения формата Ktav как такового — для последних см.
[`ktav-lang/spec`](https://github.com/ktav-lang/spec/blob/main/CHANGELOG.ru.md).

## Unreleased

Синхронизация с крейтом `ktav` 0.7.0 и `ktav-lang/spec` 0.7.0 (было
`0.6.0-4-gc9593e8` — отстаёт даже от `0.6.4`, так что попутно
подтянуты и патч-изменения 0.6.x). Спецификация добавляет
**квотированные сегменты ключа** (§ 5.3.3: сегмент ключа можно
обернуть в `"`, `'` или обратную кавычку; содержимое внутри не
обрезается, структурные байты `. : , { } [ ]` внутри — обычное
содержимое) и экранирование **`\uXXXX`** (§ 3.7.1; только в ключах и
инлайн-значениях, не в построчных скалярах и не в многострочных
блоках).

- LSP: `ktav = "0.7"` (было `"0.6"`); `rust-version` поднят до `1.71`
  (MSRV крейта ktav 0.7).
- LSP: собственный построчный классификатор (`tokens.rs` — семантические
  токены, hover, автодополнение) и сканер структуры документа
  (`symbols.rs`) научены не путать `:` / `.` внутри квотированного
  сегмента ключа с настоящим разделителем/точкой пути.
- LSP: исправлена найденная при аудите ошибка в
  `textDocument/formatting` — конец диапазона правки считался через
  `chars().count()` вместо байтовой/UTF-16 длины строки, что занижало
  позицию на непустой не-ASCII последней строке.
- LSP: из `reindent.rs` убрана мёртвая логика про маркеры `:i`/`:f`,
  удалённые ещё в spec 0.5.0; построенные на них тесты переписаны.
- Грамматика TextMate (`grammars/` + синхронизированный
  `vscode/syntaxes/`): добавлены квотированные ключи и
  `\uXXXX`-экранирование.
- Подмодуль spec закреплён на `04f867f` (`v0.7.0`).

## [0.6.1] — 2026-06-05

- Документация: все примеры в README переписаны под синтаксис спецификации 0.6 (голые числа вместо удалённых маркеров `:i`/`:f`; комментарии `##` вместо `#`).
- LSP: удалены `:i`/`:f` из элементов автодополнения (типизированные маркеры удалены в spec 0.5).
