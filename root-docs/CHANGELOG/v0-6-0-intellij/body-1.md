>>>>> lang=en
### IntelliJ plugin

- `KtavLexer` lexes escaped key segments (`\\ \. \: \, \} \] \{ \[ \n \r`),
  so a key containing an escaped dot or colon highlights as one key.

>>>>> lang=ru
### IntelliJ plugin

- `KtavLexer` лексирует экранированные сегменты ключа
  (`\\ \. \: \, \} \] \{ \[ \n \r`), поэтому ключ с экранированной
  точкой или двоеточием подсвечивается как один ключ.
