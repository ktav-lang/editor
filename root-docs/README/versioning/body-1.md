## Versioning

Single semver across the monorepo: All four
subprojects publish under the same tag at the same time. The
CHANGELOG lists changes per subproject under each version heading.

>>>>> lang=ru
## Версионирование

Единый semver на весь monorepo: все четыре
подпроекта публикуются под одним тегом одновременно. CHANGELOG
перечисляет изменения по подпроектам внутри каждого раздела версии.
