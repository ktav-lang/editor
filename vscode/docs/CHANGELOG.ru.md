# Журнал изменений

**Languages:** [English](../CHANGELOG.md) · **Русский** · [简体中文](CHANGELOG.zh.md)

## Не выпущено

Все три компонента (`ktav-lsp`, расширение VS Code, плагин IntelliJ)
переходят на 0.8.0 синхронно с crate `ktav` и спецификацией — см.
корневой [`CHANGELOG.md`](../../CHANGELOG.md) (раздел
«Не выпущено») для деталей.

## 0.5.0

- В комплекте `ktav-lsp 0.5.0` (синхронизация с ktav 0.5.0 + spec 0.5.0).
- TextMate-грамматика: шаблон комментариев изменён на `##` (spec 0.5.0).
- TextMate-грамматика: убраны шаблоны типизированных маркеров `:i`/`:f`.
- TextMate-грамматика: добавлены шаблоны инлайн-составных конструкций
  (`{key: val, …}`, `[v1, v2, …]`), escape-последовательностей и
  числовых литералов hex/oct/bin.
- Лицензия: двойная `MIT OR Apache-2.0`.

## 0.3.1

- В комплекте `ktav-lsp 0.3.1` (синхронизация с ktav 0.3.1 + spec 0.1.1).
- Структура документа (document symbols) теперь перечисляет элементы
  массива верхнего уровня как записи `[0]`, `[1]`, ….

## 0.1.0

Первый релиз.

- Подсветка синтаксиса для файлов `.ktav` через общую TextMate-грамматику
- Сопоставление скобок `{}` `[]` `()`
- Переключение комментария (`#`)
- Автоотступ внутри составных конструкций
